          Range and units

          Range values are sent in the selected units. Changing PV units converts the display and range without changing the output.

          Damping
          Loop test

          Fixes the 4–20 mA output so you can check the loop end to end. The output stops following the process until you exit.

          Loop current trim (D/A trim)

          Needs a reference milliammeter in the loop. Corrects the transmitter's output so 4 and 20 mA are exact.

          Sensor trim

          Corrects the sensor reading against a reference value. Uses HART common-practice Commands 80–83, which not every device supports.

          Live sensor reading—

          Apply the reference value, wait for the live reading to settle, then enter the calibrator's value. Do the lower point first.

          Zero and push-button ranging

          These use the value the device measures right now. Bring the input to the reference value first and let it settle.

          Advanced

          Turning the 4–20 mA output off parks it at 4 mA for multidrop use.
